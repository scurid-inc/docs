Using Scurid Server and App you can create organizations.

### Pre-requisites
1. Ensure that you have successfully installed and configured Scurid Server and App.
2. Ensure that you have successfully onboarded the user.

## Creating an Organization
1. Open Scurid App and login with your passphrase created during the onboarding process. ![onboarding process](../img/v23-0-2/login.png)
2. Click on `Organizations` then click on `Add Organization` ![onboarding process](../img/v26-1-2/orgone.png)
3. Fill in the required details and click on `Create Organization`. ![organization](../img/v26-1-2/orgtwo.png)
4. The organization is created and can be seen in the list of existing organizations. ![organization](../img/v26-1-2/orgthree.png)

## Add device to Organization
1. Select an Organization from list of Organizations. ![organization](../img/v26-1-2/orgfour.png)
2. Click on `Add Device` ![organization](../img/v26-1-2/orgfive.png)
3. Search the device to be added through the search box.
4. Select the device. ![organization](../img/v26-1-2/orgsix.png)
5. The device is now added to the Organization. ![organization](../img/v26-1-2/orgseven.png)!

## Check Identities allotment status
1. Select an Organization from list of Organizations. ![organization](../img/v26-1-2/orgfour.png).
2. Click on `Identities Overview` ![organization](../img/v26-1-2/totalidcount.png)

## Update maximum identities limit for each agent
1. Select an Organization from list of Organizations. ![organization](../img/v26-1-2/orgfour.png).
2. Click on `Settings` ![organization](../img/v26-1-2/updateidcount.png)
3. Update the count.
4. Click on the  `Save` button on the bottom right hand side.
5. Identities limit per agent is updated now!

## Delete Organization
1. Select an Organization from list of Organizations. ![organization](../img/v26-1-2/orgfour.png).
2. Click on `Settings` ![organization](../img/v26-1-2/updateidcount.png)
3. Click on `Delete Organization` button.
4. Click on `Delete` button.
5. Organization is deleted!
