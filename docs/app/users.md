Using Scurid Server and App you can create and invite users in your organization to work with you.

### Pre-requisites
Ensure that you have successfully installed and configured Scurid Server and App.

## Creating and inviting a user
1. Open Scurid App and login with your passphrase created during the onboarding process. ![onboarding process](../img/v23-0-2/login.png)
2. Click on `Settings` then `Users` and click on Add new user. ![onboarding process](../img/v23-0-2/invite-user.png)
3. Fill in the required details and click on `Invite`. ![onboarding process](../img/v23-0-2/invite-form.png)
4. The user will receive an email with an invite code valid for 24hrs. If the user fails to complete the invitation process within 24hrs, you can resend the invite code by filling up the invite form.

## Accepting an invite
1. Download the app from [Downloads](https://scurid.com/downloads)
2. Launch the app and toggle to `Sign into an existing server`
3. Click on ![Accept your invitation](../img/v23-0-2/scurid-launch.png)
4. Enter the server and port your were invited to and click on `Next`. ![Accept your invitation](../img/v23-0-2/existing-server-info.png)
5. Complete the form, including the invite code you received in your email and click on `Next`. ![Accept your invitation](../img/v23-0-2/accept-user-invite-form.png)
6. Once done, app will reload to show the login page. Click on `Sign into an existing server` and login with your email and password you just created. ![Accept your invitation](../img/v23-0-2/invited-user-login.png)

## Add a Device User

### Add a Device User with Username and Password
1. Open Scurid App and login with your passphrase created during the onboarding process. ![onboarding process](../img/v23-0-2/login.png)
2. Click on `Users`. ![onboarding process](../img/v26-1-2/devusertwo.png)
3. Click on `Add User` button, a pop up box will appear.
4. Select `With Username and Password`. ![device user registration](../img/v26-1-2/devuserone.png)
5. Fill up the user details and click on `Enroll` ![device user registration](../img/v26-1-2/devuserthree.png)
6. A confirmation message will appear and the user is enrolled. ![device user registration](../img/v26-1-2/devuserfour.png)
7. The newly added user can be seen in the list. ![device user registration](../img/v26-1-2/devuserfive.png)

### Add a Device User with Biometrics
1. Open Scurid App and login with your passphrase created during the onboarding process. ![device user registration](../img/v23-0-2/login.png)
2. Click on `Users`. ![device user registration](../img/v26-1-2/devusertwo.png)
3. Click on `Add User` button, a pop up box will appear.
4. Select `With Facial Biometrics`. ![device user registration](../img/v26-1-2/devuserone.png)
5. Fill up the form with details of the user and click `Enroll` . ![device user registration](../img/v26-1-2/devuserthirteen.png)
6. An invite will be delivered on the provided email. ![device user registration](../img/v26-1-2/devuserfifteen.png).
7. Go to the link provided in the email and click on `Continue` . ![device user registration](../img/v26-1-2/devusersixteen.png).
8. Accept the terms and conditions by clicking on `Accept`. ![device user registration](../img/v26-1-2/devuserseventeen.png).
9. Grant web camera access. ![device user registration](../img/v26-1-2/devusereighteen.png).
10. Allow the portal to capture the user's facial biometrics. ![device user registration](../img/v26-1-2/devusertwenty.png).
11. A confirmation message will be provided. ![device user registration](../img/v26-1-2/devusertwentyone.png).
12. The user shall now appear in the list of Device Users.

## Reset Password of a Device User
# Reset Password of a Device User with Username and Password
1. Open Scurid App and login with your passphrase created during the onboarding process. ![device user password reset](../img/v23-0-2/login.png)
2. Click on `Users`. ![device user password reset](../img/v26-1-2/devusertwo.png)
3. Select the user from the list of registered users.
4. Click on Reset Password. ![device user password reset](../img/v26-1-2/devusersix.png)
5. Click on Send Code. ![device user password reset](../img/v26-1-2/devuserseven.png)
6. A code will be delivered on the registered email of the user.
7. Fill up the password reset form with new password and received code, and click on `Update Password` button. ![device user password reset](../img/v26-1-2/devusernine.png)
8. The password is reset now!

## Delete a Device User
1. Open Scurid App and login with your passphrase created during the onboarding process. ![device user deletion](../img/v23-0-2/login.png)
2. Click on `Users`. ![device user deletion](../img/v26-1-2/devusertwo.png)
3. Select the user from the list of registered users.
4. Click on delete icon on the top right hand side. ![device user deletion](../img/v26-1-2/devuserten.png)
5. Click on `Confirm` button. ![device user deletion](../img/v26-1-2/devusereleven.png)
6. The user is deleted!

## Assign User to a Device
1. Open Scurid App and login with your passphrase created during the onboarding process. ![device user assignment](../img/v23-0-2/login.png)
2. Click on `Agents` and select an agent to which the user has to be added. To select the agent, click on the agent modal. ![device user assignment](../img/v26-1-2/devusertwentytwo.png).
3. Click on the `User Access` tab. ![device user assignment](../img/v26-1-2/devusertwentythree.png).
4. A list of available users will be shown under `User Access` section.
5. Click on the addition icon available at the extreme right of the candidate user. ![device user assignment](../img/v26-1-2/devusertwentyfour.png).
6. The user is now added to the device. ![device user assignment](../img/v26-1-2/devusertwentyfive.png).
